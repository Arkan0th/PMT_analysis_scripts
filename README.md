# PMT_analysis_scripts
Useful PMT analysis scripts (some were used in my BC thesis)
------------------------------------------------------------

## Scripts

- **PMTAF_complementary** are add-on scripts based for [**PMTAF**](https://github.com/karbenatek/PMTAF.git)

- **WUT-PMT-tester_complementary** are add-on scripts for [**WUT PMT tester**](https://git.hyperk.org/fd2/wut-pmt-tester/wut-pmt-tester)

For detailed info look into dedicated repos (until this repo will be finished)
